# 二次元风格中文介绍视频

为「雷池 WAF 社区版 · Android 客户端」制作的 3 分 38 秒二次元风格中文介绍片。
画面由 Python(Pillow) 逐帧程序化绘制，配乐由 Python(numpy+scipy) 程序化合成，
中文讲解由 Edge-TTS 生成，无需任何外部素材或素材授权。

## 成片

- 分辨率：1920×1080 @ 30fps
- 时长：218.4 秒（3:38）
- 编码：H.264(OpenH264) + AAC 立体声 48kHz
- 响度：-15.5 LUFS / 真峰 -1.5 dBTP（网络视频通用）
- 文件：`safeline_intro_v4.mp4`

## v4 重做说明（响应 Issue #6「开场刺耳 / 人物不好看 / 声音重做」）

这一版是**推倒重来**，三块分别重写：配乐、配音、角色形象。

### 一、配乐：从「又薄又尖」改成「有底、不刺」

把 v3 的开头单独拆出来量，问题可复现：

| 指标（0~19 秒） | v3 | v4 |
|---|---|---|
| 低频 <250Hz 能量占比 | 0.2% ~ 6% | **30% ~ 66%** |
| 频谱质心 | 2000 ~ 2600 Hz | **891 Hz**（纯画面段） |
| 2~4kHz 占比 | 3.5% ~ 7.6% | **1.8% ~ 3.6%** |

改法：

1. **开头就有底**：第 0 秒起铺一层「低音弦乐 + Rhodes 电钢」的低音垫，
   和声不再悬在半空。
2. **换掉管钟**：v3 前奏主音是 `tubular_bell`，起音带 2.5kHz 噪声撞击 +
   3.76/4.07 倍非谐分音，本身就带金属尖头。v4 主音改为**软起音 Rhodes 电钢**
   （30ms 鼓包起音）与钢片琴，管钟全曲弃用。
3. **母带削高频**：4.5kHz 搁架 -4dB + 6.8kHz 低通 + 2.6kHz 峰值 -2.5dB，
   从根上砍掉「刺」。
4. **打击乐柔化**：镲片/沙锤/踩镲的高频带整体下移（如沙锤 3800~12000 → 3000~9000），
   音量同步收小。
5. **力度更轻**：动态收窄到 3 档，靠「加不加元素」推进，而不是加大音量。

### 二、配音：换音色，去掉沙沙的毛刺

| 指标（全片旁白） | v3（XiaoyiNeural） | v4（XiaoxiaoNeural） |
|---|---|---|
| 频谱质心 | 3625 Hz | **2296 Hz** |
| 6kHz 以上能量 | 27.5% | **12.8%** |

- 音色：`zh-CN-XiaoyiNeural` → `zh-CN-XiaoxiaoNeural`（温柔女声）
- 语速：`+8%` → `-4%`（娓娓道来）
- 音调：`+25Hz` → `-2Hz`（v3 抬调把共振峰整体上移，是「刺」的来源之一）
- 后处理链加 `equalizer 2.8k -2dB`、`equalizer 7k 搁架 -3dB`、`deesser`、限幅

### 三、角色「雷小池」：从头重画

v3 的角色是「蓝色头盔 + 平脸」——头发糊成一整块、脸是正圆、眼睛黏在脸上、
身体是一个白色三角。v4 按 Q 版比例重新立结构：

- 头发改用**整条闭合轮廓**描画（Chaikin 平滑），分后发 / 双马尾 / 鬓发 / 刘海四层，
  不再用一堆椭圆硬拼出「头盔」
- 脸改成「上圆下收」的蛋形，有下巴；刘海尖端停在眉毛高度，露出额头与眼睛
- 眼睛分层：眼白 → 虹膜渐变 → 瞳孔 → 双高光 → 上睫毛 → 下眼线，眉毛独立
- 身体有**水手领 + 领结 + 袖口 + 手**，手臂是曲线不是直条
- 全部件带柔和阴影 / 高光（离屏模糊合成），不再纯平涂

### 四、顺手修的两个流程 Bug

- `timeline.py` 写 timeline.json 时用的是硬编码 `/tmp/work/...`，改成写到旁白目录所在目录
- 画面渲染此前直接用 `storyboard.py` 里写死的各幕时长，与 timeline 算出的时长会漂移；
  现在 `render.py` 渲染前统一以 timeline 为准（`sync_durations_from_timeline`）
- `chara_talk` 场景的气泡与底部字幕此前是两套文本（气泡是旧稿），现在气泡文案
  以字幕为唯一来源，且底部不再重复画一条

## 生产流程

```bash
pip install pillow numpy scipy edge-tts
./build.sh                  # 一键：配音 -> 分镜 -> 配乐 -> 画面 -> 混流
```

分步说明：

```bash
python voice.py   .video/narration   # 1. 合成 11 句中文旁白（断点续跑）
python timeline.py .video/narration  # 2. 由旁白长度算各幕时长 -> .video/timeline.json
python subtitles.py .video/narration # 3. 切字幕条（不切断西文单词）
python bgm.py 218.4 .video/audio/bgm.wav   # 4. 合成配乐
python render.py                     # 5. 逐帧渲染（多进程，约 10 分钟）
python mixrun.py .video              # 6. 侧链闪避 + 混音 + loudnorm
python encode.py --frames .video/frames --meta .video/frames/meta.json \
    --audio .video/audio/mix.wav --out .video/out/safeline_intro_v4.mp4
```

> 拼接**刻意不用 xfade**：转场会吃掉时长（每幕 0.6s），画面会比旁白越错越多。
> 每幕自带缓入缓出，硬切已经足够顺，`encode.py` 里还有时长自检。

## 模块

| 文件 | 职责 |
|------|------|
| `theme.py` | 配色、渐变、发光、卡片、文字排版（含缓存） |
| `character.py` | Q 版角色「雷小池」矢量绘制（闭合轮廓法，眨眼/口型/挥手/呆毛动画） |
| `bgfx.py` | 背景特效：渐变天空、樱花瓣粒子、光晕、太阳射线 |
| `ui.py` | 伪 UI 组件：手机壳、指标卡、徽章、标题 |
| `storyboard.py` | 12 幕分镜脚本与文案（时长以 timeline 为准） |
| `render.py` | 逐帧渲染引擎（多进程） |
| `bgm.py` | 配乐编曲（8 小节和声循环 / 低音垫 + Rhodes，削高频母带） |
| `dsp.py` | DSP 积木：滤波、均衡、饱和、卷积混响、压缩、侧链、抖动 |
| `instruments.py` | 乐器合成：钢琴 / **Rhodes 电钢** / 弦乐群 / 钟琴 / 电贝斯 / 鼓组 |
| `voice.py` | 中文解说文案 + Edge-TTS 合成（Xiaoxiao 音色 + 去毛刺链） |
| `timeline.py` | 时间轴：场景顺序、各幕时长、旁白落点 |
| `subtitles.py` | 字幕切条与断行 |
| `subtitle_draw.py` | 字幕底衬绘制 |
| `mix.py` | 人声 + 配乐混音、侧链闪避、响度归一 |
| `encode.py` | 编码与合成成片 |

## 说明

> 本构建用 ffmpeg 无 `libx264`，H.264 编码走 `libopenh264`。
> 字体使用系统内置 `WenQuanYi Zen Hei`（版权不涉第三方素材）。
> 配音由 Edge-TTS 生成（微软在线语音合成，非真人录音但为真人声学模型），
> 画面同时保留字幕，方便静音观看。
>
> 声音全部程序化生成 / 合成，**不含任何第三方音乐素材**，无版权风险。
