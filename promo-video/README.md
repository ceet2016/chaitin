# 二次元风格中文介绍视频

为「雷池 WAF 社区版 · Android 客户端」制作的 3 分 17 秒二次元风格中文介绍片。
画面由 Python(Pillow) 逐帧程序化绘制，配乐由 Python(numpy+scipy) 程序化合成，
中文讲解由 Edge-TTS 生成，无需任何外部素材或素材授权。

## 成片

- 分辨率：1920×1080 @ 30fps
- 时长：196.7 秒（3:17）
- 编码：H.264(OpenH264) + AAC 立体声 48kHz
- 响度：-15.7 LUFS / 真峰 -1.5 dBTP（网络视频通用）
- 文件：`safeline_intro.mp4`

## 音频设计（v3 重做）

v1 像电子琴（纯正弦叠加、8 秒死循环），v2 修了音色却仍有三个硬伤，
这一版就是冲这三条去的：

1. **和声走调**：v2 的和弦没写低音，贝斯一律取 voicing 最低音，
   `C/E` 和 `C` 两小节实际都响在 E 上，低音线出现 `F→E→D→Bb→G→E→F→Bb`
   这种不规则跳进，进行散架。v3 的 `Chord` 显式带 `bass`，
   低音线单独设计成 `F-G-A-Bb-C-C-F-Bb` 的级进。
2. **机械重复**：v2 每小节内容完全一样，27 秒的段落里 12 次原样复制，
   鼓点是抬拍上的固定动圈（咚—哒 50~100 次），像节拍器。
   v3 改成 72 BPM 的「咚—哒-哒」律动 + ghost 军鼓 + 16 分沙锤，
   小节内容由和声位置决定，段落边界才有加花。
3. **刺耳**：v2 把打击乐、高音木琴、电钢全挤在 1.5~3k，
   频谱质心 2~2.5kHz（参考值：华语流行男声约 2kHz）。
   v3 换掉木琴，主奏改三角钢琴 + 弦乐群，质心降到 330Hz 左右。

v3 的四个改进：

1. **音色**：每个音都有起音噪声 + 基音缺失的音分比例 +
   逐分音各自衰减（`dsp.py` / `instruments.py`）。
   管钟用 Strickland 相位修正法合，起音不炸。
2. **配器**：三角钢琴（主奏）+ 弦乐群（和声，每音位 5 把琴微失调）+
   管钟/钟琴（落点）+ 电贝斯（指弹）+ 原声鼓组，8 小节和声循环。
3. **编排**：8 个段落划分成 4 个动态档（0 稀疏 → 3 全奏），
   前奏与「安全」段整段留白不给鼓，末段靠镲片渐强推上去。
4. **人声**：中央 C 音域的钢琴叙事 + 只在留白处出现的旋律声部，
   主旋律遇到旁白整块让位；混音侧链闪避 6.5dB（v2 是 9dB，压得太死）。

实测（全片音频轨）：

| 指标 | v2 | v3 |
|------|----|----|
| 频谱质心 | 1886 Hz | 332 Hz |
| 2 秒窗口 RMS 起伏 | 2.0× | 9.4× |
| 动态档 | 恒响 | 4 档 |
| 节奏脉动相关性 | 散（1.3s 噪声） | 0.65 @ 1.67s（= 半小节） |

## 生产流程

```bash
pip install pillow numpy scipy edge-tts
./build.sh                  # 一键：配音 -> 分镜 -> 配乐 -> 画面 -> 混流
```

分步说明：

```bash
python voice.py   .video/narration   # 1. 合成 11 句中文旁白（断点续跑）
python timeline.py .video/narration  # 2. 由旁白长度算各幕时长
python subtitles.py .video/narration # 3. 切字幕条（不切断西文单词）
python bgm.py 196.7 .video/audio/bgm.wav   # 4. 合成配乐
python render.py                     # 5. 逐帧渲染（多进程，约 6 分钟）
python mixrun.py .video              # 6. 侧链闪避 + 混音 + loudnorm
python encode.py --frames .video/frames --meta .video/frames/meta.json \
    --audio .video/audio/mix.wav --out .video/out/safeline_intro.mp4
```

> 拼接**刻意不用 xfade**：转场会吃掉时长（每幕 0.6s），画面会比旁白越错越多。
> 每幕自带缓入缓出，硬切已经足够顺，`encode.py` 里还有时长自检。

## 模块

| 文件 | 职责 |
|------|------|
| `theme.py` | 配色、渐变、发光、卡片、文字排版（含缓存） |
| `character.py` | Q 版角色「雷小池」矢量绘制（眨眼/口型/挥手/呆毛动画） |
| `bgfx.py` | 背景特效：渐变天空、樱花瓣粒子、光晕、太阳射线 |
| `ui.py` | 伪 UI 组件：手机壳、指标卡、徽章、标题 |
| `storyboard.py` | 12 幕分镜脚本与文案 |
| `render.py` | 逐帧渲染引擎（多进程） |
| `bgm.py` | 配乐编曲（8 小节和声循环 / 8 段落 / 4 动态档） |
| `dsp.py` | DSP 积木：滤波、均衡、饱和、卷积混响、压缩、侧链、抖动 |
| `instruments.py` | 乐器合成：钢琴 / 弦乐群 / 管钟 / 钟琴 / 电贝斯 / 鼓组 |
| `voice.py` | 中文解说文案 + Edge-TTS 合成 |
| `timeline.py` | 时间轴：场景顺序、各幕时长、旁白落点 |
| `subtitles.py` | 字幕切条与断行 |
| `subtitle_draw.py` | 字幕底衬绘制 |
| `mix.py` | 人声 + 配乐混音、侧链闪避、响度归一 |
| `encode.py` | 编码与合成成片 |

## 说明

> 本构建用 ffmpeg 无 `libx264`，H.264 编码走 `libopenh264`。
> 字体使用系统内置 `WenQuanYi Zen Hei`（版权不涉第三方素材）。
> 配音由 Edge-TTS 生成（微软在线语音合成，非真人录音但为真人声学模型），
> 画面同时保留字幕，方便静音观看。
>
> 声音全部程序化生成 / 合成，**不含任何第三方音乐素材**，无版权风险。
